# 🎓 AI-Academic-Portal: Intelligent Student Management System

A high-performance **FastAPI** web application featuring an asynchronous **NLP (Natural Language Processing)** engine that automatically analyzes student project descriptions to extract technical skills and calculate project complexity.

## 🚀 Key Features

* **Intelligent Project Analysis:** Uses a backend NLP logic to scan project descriptions, identifying key technologies (Python, ML, SQL, etc.) and assigning a dynamic complexity score.
* **Secure Authentication:** Implements **Bcrypt** password hashing and real-world **DNS-based email validation** to prevent fake registrations.
* **Premium Glassmorphism UI:** A modern, dark-mode dashboard with frosted-glass effects and cyan accents for a high-end user experience.
* **Full CRUD Functionality:** Students can manage their profiles, submit projects, and view their academic status in real-time.
* **Persistent MySQL Storage:** Fully relational database schema managing Students, Projects, and Courses.

## 🛠️ Tech Stack

* **Backend:** FastAPI (Python)
* **Database:** MySQL with SQLAlchemy ORM
* **Frontend:** Jinja2 Templates, CSS3 (Glassmorphism), HTML5
* **Security:** Bcrypt (Hashing), Email-Validator (DNS Verification)
* **Server:** Uvicorn (ASGI)
